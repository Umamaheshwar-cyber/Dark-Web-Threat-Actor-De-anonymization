1. Project Overview

SHADOWTRACE is a full-stack defensive cybersecurity research platform that ingests, correlates, and exports threat actor intelligence using both synthetic training data and authorized public CTI feeds. It is designed to demonstrate how multi-signal ensemble correlation, OPSEC hygiene tracking, and STIX 2.1 intelligence sharing can work together in a single operator-facing platform without any dark-web, Tor, or unauthorized network access.

The platform ships with a dark-themed single-page command-center dashboard served directly from FastAPI, providing real-time correlation analytics, interactive relationship graphs, timeline investigation tracking, and one-click export to STIX 2.1 and Markdown briefings.

3. System Architecture

backend/main.py

FastAPI application shell. Mounts all domain routers, serves static frontend assets, provides /api/health probe.

backend/models.py

All Pydantic schemas: Case, Actor, Evidence, CorrelationAssessment, STIX, MISP, CIRCL models (35+ types).

backend/correlation_engine.py

Core analytics — Levenshtein, Jaro-Winkler, n-gram algorithms + 5-dimension ensemble correlation with dynamic weight renormalization.

backend/provenance.py

SHA-256 canonical integrity hashing with Admiralty A-1 / B-2 provenance metadata. Strict boundary between observed data and analytical conclusions.

backend/stix_export.py

STIX 2.1 bundle builder. Generates deterministic UUIDv5 objects for threat-actor, observed-data, indicator, relationship, and report SDOs.

backend/audit.py

Append-only JSONL audit logger. Sanitizes all log writes to prevent credential leakage. Supports reverse-chronological query filtering.

backend/reporting.py

9-section structured JSON report generator + professional Markdown briefing formatter. Differentiates synthetic vs. authorized CTI metadata.

backend/authorized_adapter.py

Read-only MISP REST adapter (MISPAdapter) and public CIRCL OSINT feed adapter (CIRCLFeedAdapter). SSL-verified, API-key-safe, pull-only.

backend/data_store.py

Multi-case JSON registry. Isolated storage layer, CIRCL sync state management, authorized MISP container appends.

backend/routers/

7 domain routers: cases, actors, evidence, analytics, search, reports, feeds (MISP + CIRCL).

frontend/

SPA dashboard with dark cyber-ops theme, CRT scanlines, Matrix canvas, live UTC clock, 12-section navigation, modal dialogs, toast notifications.

data/cases/

4 case JSON files: CASE-2026-09X (ShadowX), CASE-2026-02B (CipherPhantom), CASE-2026-03C (GhostWeaver), CASE-AUTH-MISP (live feed container).

5. Correlation Engine — Multi-Signal Ensemble

The correlation engine combines five independent analytical dimensions into a single weighted confidence score. When a signal is unavailable (e.g. authorized CTI feeds don't publish stylometry data), the engine renormalizes weights dynamically across only the available signals — it never treats missing data as zero or as a positive contribution.

Alias Similarity Algorithms

AlgorithmWeightDescription
Levenshtein Edit Distance35%Normalized edit distance — minimum character insertions, deletions, substitutions
Jaro-Winkler35%Prefix-weighted string similarity — higher scores for shared leading characters
2-gram Character Overlap (Jaccard)30%Bigram set intersection ÷ union — structural character pattern matching
Confidence tiers: HIGH (≥ 75%), MEDIUM (≥ 50%), LOW (< 50%), UNAVAILABLE (no signals available from source). All confidence values are analytical indicators — explicitly not legal identity attribution.

IOC Type Detection

The STIX export auto-detects observable types from raw evidence identifiers: IPv4, IPv6, URLs, SHA-256 / SHA-1 / MD5 file hashes, domain names, PGP keys, cryptocurrency wallets, and forum aliases — each mapped to the appropriate STIX SCO.
